# 魔法戦争 バージョン1

魔法だけで塔を登る 2.5D ピクセルアートのアクション。全 20 層、ソロと最大 4 人協力。

## 遊び方

```bash
node server.mjs
```

ブラウザで http://localhost:8080 を開きます(パッケージのインストールは不要、Node 18 以上)。
マルチは「仲間と挑む → 部屋を作る」で部屋番号を出し、同じネットワークの仲間に表示された URL と番号を伝えます。

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー |
| 回避 | スペース(長押しで必殺技) |
| 魔法 | 1〜9, 0 |
| 一時停止(ソロ) | Esc |
| 消音 | M |

## 流れ

1. 各層のはじめに、プレイヤーごとにランダムな 10 個の魔法から 2 つ選ぶ(所持魔法を選ぶとランクアップ)
2. ボス部屋で戦う(通常攻撃なし、魔法のみ)
3. 勝つと SP を獲得し、魔法のランク(最大 10)かステータス(上限なし)に自由に振る
4. 2 層を倒した後からは報酬画面で魔法を捨てられる。11 個以上になる場合はその場で必ず捨てる
5. 全滅すると魔法・ステータス・必殺技をすべて失い第 1 層へ。見つけた知識だけは残る
6. マルチでは倒れても、誰かがボスに勝てば次の階で復活する

第 1 層のはじめに必殺技を 1 つ選ぶ(20 種のうち 10 個が候補、死ぬまで変更不可)。溜まったらスペース長押しで発動。

## 構成

- `src/sim/` ゲームロジック(描画に依存しない。サーバーでもブラウザでも同じものが動く)
  - `skills.js` 魔法 80 種とランク効果、ステータス
  - `ults.js` 必殺技 20 種、`synergies.js` 隠し効果、`reactions.js` 元素反応とコンボ(ネタバレ注意)
  - `bosses.js` ボス 20 体の技・ギミック・HP/攻撃/防御の表
  - `battle.js` 戦闘、`session.js` 進行
- `src/render/` 2.5D 描画。`bosses-art.js` `hero.js` `stage.js` はこのゲームのオリジナル絵をコードで描いたもの
- `src/ui/` メニューと HUD
- `vendor/pixelfx/` エフェクト(MIT License、[pixelfx](https://github.com/patch-gg/pixelfx))
- `server.mjs` 配信とマルチの部屋(依存なしの WebSocket)

## 調整とテスト

```bash
node tests/flow.mjs
```
```bash
node tests/balance.mjs 5 1 .9 balanced,tank
```
```bash
node tests/diag.mjs 13 20
```

`flow` は進行ルールの確認、`balance` はボットによる全層の通し対戦、`diag` は指定の階で何に倒されているかの内訳です。
数値を変えるなら `src/sim/bosses.js` 末尾の `BOSS_HP` `BOSS_ATK` `BOSS_DEF` と `src/sim/skills.js` の `STATS` から始めるのが手軽です。
